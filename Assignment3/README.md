# 🚀 FastAPI  – CRUD Operations 

This project demonstrates complete **CRUD operations using FastAPI** as part of internship training practice.

## 📌 Features Implemented

- ➕ Add new products using **POST /products**
- 🔄 Update product price and stock using **PUT /products/{product_id}**
- 🗑️ Delete products using **DELETE /products/{product_id}**
- 📋 View all products using **GET /products**
- 🔎 View single product details using **GET /products/{product_id}**
- 📊 Inventory audit summary using **GET /products/audit**
- ⭐ Bonus: Apply category-wide discount using **PUT /products/discount**
